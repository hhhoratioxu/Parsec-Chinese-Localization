# Changelog

Experimental initial companion release, not stable native localization.

- Added version-gated Windows public-settings reads and explicit page navigation.
- Added automated tests and Windows/macOS packaging workflows.

Native text replacement: 0%. macOS AX integration is unavailable. Test results and build status are tracked separately in docs/VALIDATION.md.
